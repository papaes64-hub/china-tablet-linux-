# Золотой Linux-планшет 2 / Golden Linux Tablet 2

**Дата начала:** 12 ноября 2026  
**Назначение:** точка продолжения исследования N4020 при смене/переполнении чатов ChatGPT.  
**Статус:** CachyOS GOLD — рабочий эталон; следующий опыт — AuraDE, сначала на N4020.

> Этот файл — журнал проекта, а не установочный скрипт. Проверенные факты отделяем от гипотез. Секреты, приватные резервные образы, данные Google и иные персональные файлы в публичный GitHub не публикуем.

## Рабочая машина

- Трансформер/планшет **Intel Celeron N4020**, экран **1366×768**, файловая система Btrfs, внутренний SSD класса **256 ГБ**.
- **CachyOS x86_64**, ядро **7.3.3-1-cachyos**, **KDE Plasma 6.8.2 / Wayland**.
- **Silead MSSL1680**: исходная firmware `mssl1680.fw`, MD5 `86e979b61f02ebad6b20ac66a7708c29`; Python evdev filter v10; `silead-unfold` и `silead-longpress` активны. Владелец подтвердил точное касание и длительное нажатие для контекстного меню.
- **Kionix display/base sensors:** планшетный режим при **190°**, антидребезг **0,70 с**. Отключение/возврат физической клавиатуры и тачпада подтверждены; автоповорот KDE работает. В текущей CachyOS HTIX5288 touchpad распознаётся через udev `ID_INPUT_TOUCHPAD=1`, а не по слову Touchpad в имени. Исправление есть в ветке.
- **Plasma Keyboard RU+EN**, трей и автоматический запуск управляющих компонентов — подтверждено удобно в реальном использовании.
- **Waydroid 1.6.3**: Android 13 / LineageOS 20 x86_64 **GAPPS**, интернет и Google Play работают, нужные приложения установлены. Поворот Android исправно следует ориентации экрана **без отдельных костылей Waydroid**.
- **LinuxShared v3:** `Download`, `Documents`, `Pictures` видны Android через FUSE. Запись Android → Linux в Download подтверждена; для отдельных путей использована ограниченная ACL для актуального Android UID **10141**. При новой установке UID перепроверить.

## Следующий этап: AuraDE, только N4020

**Пользователь в командировке, N95 недоступен**; VM на N95 не является первым этапом.

1. Исследовать AuraDE **v1.3.2**, репозиторий https://github.com/Cam396/aurade, и прочитать [официальную инструкцию установки рядом с KDE](https://github.com/Cam396/aurade/blob/main/docs/existing-arch.md).
2. На текущем N4020 начать с **проверки зависимостей, занимаемого места и конфликтов пакетов** без установки или изменения SSD. Дальше — только обратимая установка отдельной **сессии AuraDE**, если совместимость с CachyOS подтверждается. Не запускать ISO-установщик с очисткой SSD.
3. Основной KDE/Wayland — эталон и способ отката через экран входа в сеанс; при первом входе AuraDE желательно внешнее USB-устройство ввода.
4. **Важно:** настройка шарнира управляет устройствами через **KWin D-Bus**, автоповорот через **KScreen**, а экранная клавиатура — Plasma Keyboard. В отдельной сессии AuraDE они **не должны считаться автоматически перенесёнными**. Проверять сенсор → управление вводом → ориентацию → клавиатуру → Android по одному.
5. **Безопасность:** встроенный Chromium AuraDE 1.3.2 основан на development snapshot Chromium 158 и не получает регулярные upstream исправления безопасности. Использовать только как экспериментальное окружение, не для чувствительных сайтов и учётных записей. Android AuraDE не равнозначен уже работающему Waydroid + GAPPS.
6. Если стабильный рабочий вариант не получается, оставляем GOLD без изменений и фиксируем точные препятствия.

## Правила продолжения работы с ChatGPT

- Начинай с этого файла и [отчёта GOLD](RESTORE-2026-11-11.md), не проси заново всю историю.
- Команды для пользователя должны быть **совместимы с fish 4.9.3** (или явно заключать Bash-код в `bash -c`).
- **Один практический шаг**, затем анализ результата. Не повторять уже подтверждённые тесты и не переписывать работающие контроллеры ради косметики.
- Любую потенциально опасную запись на диск, `pacman -Syu`, изменение системных служб, разделов и загрузчика сопровождать проверкой исходных условий и откатом.
- Разделять `ПОДТВЕРЖДЕНО`, `ПРЕДПОЛОЖЕНИЕ`, `СЛЕДУЮЩИЙ ТЕСТ`, `ОТКАТ`. Сохранять новые рабочие исправления в GitHub.
- Никаких приватных архивов или персональных данных в публичный репозиторий.
