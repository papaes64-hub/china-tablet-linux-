# Linux Tablet N4020 — CachyOS GOLD restoration / Восстановление GOLD

**Date / Дата:** 11 November 2026 (follow-up plan: 12 November 2026)  
**Scope:** one owner-tested N4020 convertible, not a generic installer. The October 24 configuration remains documented separately.

## Подтверждено на устройстве (11.11.2026)

- Чистая CachyOS x86_64, **kernel 7.3.3-1-cachyos**, **KDE Plasma 6.8.2**, Wayland, дисплей 1366×768.
- Silead MSSL1680: прошивка **38 544 bytes**, MD5 `86e979b61f02ebad6b20ac66a7708c29`; пользовательский фильтр `silead-unfold.py` v10 и `silead-longpress.py` активны через systemd; исправленное сенсорное устройство и виртуальная мышь видны. Владелец подтвердил работу длительного нажатия и контекстного меню.
- Kionix `i2c-KIOX020A:00` + `i2c-KIOX010A:00`: измеренный переход LAPTOP/TABLET через **190°**, выдержка 0,70 с. Физическая клавиатура и тачпад переключаются автоматически.
- **Обязательная поправка к первоначальной инструкции:** в новой системе два устройства `HTIX5288:00 0911:5288` без слова `Touchpad`. Не использовать стабильные номера `event9`/`event10`: настоящий тачпад определяется udev-свойством **`ID_INPUT_TOUCHPAD=1`**. Исправление уже внесено в `scripts/linux-tablet-hinge-kde.py` данной ветки.
- Автоповорот KDE и экранная клавиатура Plasma с RU/EN работают; сессия KDE настроена для автоматического запуска трёх контроллеров.
- **Waydroid 1.6.3, Android 13 (LineageOS 20), x86_64, GAPPS:** Android запускается, касания работают, **ориентация меняется без дополнительных скриптов для Waydroid**, Google Play и интернет подтверждены, приложения скачаны.
- Сеть Waydroid: мост `waydroid0` 192.168.240.1/24; UFW должен разрешать DHCP/DNS и маршрутизацию через внешний интерфейс. Устройство первоначально показывало «нет сети», несмотря на рабочие IPv4/DNS/ICMP. После настройки `captive_portal_mode=0` и перезапуска Android пользователь подтвердил Google Play и доступ к приложениям. **Примечание:** отключение Android captive-portal checks влияет на обнаружение сетей, требующих авторизации; не применять без необходимости.
- **LinuxShared v3**: все три маркера подтверждены с Android через `/sdcard/{Download,Documents,Pictures}/LinuxShared`. Запись из Android в `~/Загрузки/Android-Test` подтверждена для UID **10141** после адресного ACL. Для `Документы` и `Изображения` ACL также добавляли; независимая проверка записи в них в переписке не зафиксирована. UID может измениться в других установках, не применять рекурсивный `chmod 777`.

## Резервная копия / Recovery

**Старые локальные** Snapper #37 и архив от 24.10 на свежей установке не найдены. Эти номера не переносить в текущую систему.

**Новая полнодисковая копия:** 11.11.2026 Clonezilla Live **3.3.3-37**, режим `device-image → local_dev → Beginner → savedisk`, исходный внутренний SSD **Wdxsky W31-256G, 238.5 GiB**, сохранение в каталог **`/Clonezilla-Images/CachyOS-GOLD-20261111`** на отдельном USB Ventoy 64 GB (NTFS). Загрузочная Clonezilla записана на **отдельный USB 16 GB**. Выбрано сжатие `zstdmt (-z9p)`, проверка образа после создания, без шифрования. На экране Clonezilla появилось **«Этот образ был сохранён успешно»**. Пользователь сообщил о завершении процесса; отдельного скриншота результата проверки образа и пробного восстановления не зафиксировано.

**Ограничения:** копия содержит приватные сведения и Android-данные, никогда не загружать её в публичный GitHub. Восстановление на внутренний SSD уничтожит его актуальные данные. Clonezilla `savedisk` — это каталог образа, **не установочный ISO**. Перед любыми новыми экспериментами убедиться, что носитель с копией читается; предпочтительно иметь вторую копию на внешнем диске.

## Next experiment / Следующий эксперимент — AuraDE на N4020

- **Target:** explore [AuraDE](https://github.com/Cam396/aurade), an independent ChromeOS/Ash-style desktop for Arch, **directly on the N4020** because the separate N95 host is unavailable during travel.
- **Preserve CachyOS GOLD:** do not use the AuraDE ISO installer on the internal SSD: it has an erase gate. AuraDE officially documents adding a separate session to an existing Arch installation; that path was **tested upstream on plain Arch/KDE**, **not** on this CachyOS tablet. Inspect dependencies and rollback before installation.
- **Device-specific caution:** current hinge input switching uses **KWin D-Bus**, autorotation uses **KScreen**, and Plasma Keyboard is KDE-specific. Those three controls will **not automatically work inside AuraDE**. System-wide Silead service may still work, but must be tested. An external USB keyboard/mouse is recommended for first login.
- **Security:** AuraDE 1.3.2 includes a Chromium 158 development snapshot, without normal upstream Chromium security fixes; treat its browser as experimental. AuraDE Android is not a substitute for the already working Waydroid/GAPPS stack without a separate compatibility test.
- **Validation order:** (1) read-only survey of current CachyOS + AuraDE package requirements; (2) reversible additional-session test on N4020 only if no conflicts; (3) touch/input/rotation/keyboard comparison; (4) keep KDE as stable default until all checks pass; (5) new checkpoint and documentation.
- **Rollback:** choose the KDE Wayland session at login; if package removal is required use AuraDE upstream instructions after checking package dependencies. The Clonezilla GOLD image remains last-resort recovery, not the everyday rollback method.

## English summary

The original one-device CachyOS setup was rebuilt on a fresh November 2026 CachyOS install and verified by its owner: Silead v10 touch and long-press, calibrated 190° hinge controls, KDE autorotation, bilingual on-screen keyboard, Waydroid 1.6.3 Android 13 GAPPS with native orientation handling and working Play Store, and Android-visible LinuxShared directories. The Waydroid Download share was shown writable by Android after targeted ACLs. A Clonezilla full-disk backup was saved successfully to external USB, while independent restore verification is still outstanding. The next phase tests **AuraDE on the N4020 directly**, without wiping the working KDE installation or assuming its KWin-based controls carry over.
